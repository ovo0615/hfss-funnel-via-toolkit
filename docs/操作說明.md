# HFSS 漏斗 Via 建模工具（網頁版）　操作說明

---

## 一、工具用途

HFSS 3D Layout 只能建立「等徑圓柱 via」，無法做出漏斗狀（堆疊雷射微孔 / stacked laser via）的錐形孔。本工具透過 **PyAEDT** 在 **HFSS 3D 模型器**中，以多段「圓錐台（cone frustum）」沿 Z 軸堆疊，組出上寬下窄的漏斗狀 via，並可直接對齊、取代既有的等徑 via。

網頁版在原本的桌面版功能之上，另提供 **Three.js 即時 3D 預覽**：參數一改，中央視窗立刻重畫漏斗形狀。

建立完成後於 AEDT 中的結果：

![漏斗 via 建立結果](images/funnel_via_result.png)

## 二、環境需求

| 項目 | 用途 | 授權／取得方式 |
|------|------|---------------|
| Windows 10／11（64 位元） | 執行環境 | 作業系統 |
| Ansys Electronics Desktop（含 HFSS） | 模擬主程式，本工具是遙控您已安裝的 AEDT（預設 **2026 R1**） | **商業授權**，請使用貴公司正式安裝版 |

> 本工具**不含**任何 Ansys 元件，也不會繞過授權。沒有已安裝且已授權的 AEDT，就無法建立幾何。

### 2-2．工具會自動處理

| 項目 | 說明 |

## 三、下載與啟動

### 3-1．下載

任選一種：

- **Source ZIP**：GitHub 專案頁 → 綠色 **Code** 按鈕 → **Download ZIP**。
- **Release ZIP**：GitHub 專案頁 → **Releases** → 下載版本化 ZIP（附 `SHA256SUMS.txt` 可驗證完整性）。

### 3-2．解壓縮

**務必先完整解壓縮到本機資料夾**（例如 `C:\Tools\hfss-funnel-via-toolkit`），不要直接從 ZIP 檢視器內執行。路徑建議避免 OneDrive 同步資料夾與網路磁碟。

### 3-3．啟動

1. 先開啟 AEDT，載入要加 via 的 HFSS 專案與設計（保持開著）。
2. 進入解壓後的 `funnel-via-web` 資料夾。
3. **雙擊 `start.bat`**。
4. 視窗會依序顯示：發布內容檢查 → Python 偵測 → 虛擬環境建立 → 套件安裝 → 連接埠檢查 → 啟動服務。
5. 服務就緒後會自動開啟瀏覽器 `http://127.0.0.1:8010`。

其他用法（在該資料夾的 PowerShell 或命令提示字元執行）：

```bat
start.bat -Port 8020
```

```bat
start.bat -CheckOnly
```

- `-Port`：8010 被其他程式佔用時改用別的埠。
- `-CheckOnly`：只做環境檢查與套件安裝，不啟動服務、不佔用連接埠。

### 3-4．結束

**關閉那個黑色／藍色的啟動視窗即停止服務**（伺服器是前景程序，不會留在背景）。若只關瀏覽器分頁，服務仍在執行。

### 3-5．資料與隱私

服務只綁定 `127.0.0.1`（本機回送位址），**不對外網開放，也不會上傳任何疊構、座標或專案資料**。所有運算都在本機完成，唯一的網路行為是首次啟動時下載 Python 套件。

## 三之二、練習用範例專案（建議先跑一次）

手邊沒有適合的板子時，可以用 repo 內附的範例專案先熟悉整個流程。

**檔案**：`Diff_Via_Example.aedtz`（位於解壓後的最上層資料夾，約 0.6 MB）

`.aedtz` 是 **AEDT 封存專案**格式，內含工具需要的兩種設計：

| 設計 | 型態 | 用途 |
|------|------|------|
| `diffViaNominal` | HFSS 3D Layout | 疊構來源（工具由此讀取真實層 Z） |
| `HFSSDesign1` | HFSS 3D | via 所在、漏斗建立的地方 |

**開啟方式**：

1. 開啟 AEDT。
2. **File → Open**，檔案類型選 `Ansys Electronics Desktop Project Archive (*.aedtz)`，選取 `Diff_Via_Example.aedtz`。
3. AEDT 會要求指定解壓位置，選一個你有寫入權限的資料夾（例如 `C:\Work\`）後確定。
4. 專案樹會同時出現 `diffViaNominal`（Layout）與 `HFSSDesign1`（HFSS 3D）。**切到 `HFSSDesign1`**。

**接著照第五節的正式流程走**，其中：

- 第 3 步「⤵ 從 3D Layout 設計讀取真實疊構」會讀到 `diffViaNominal` 的疊構。
- 第 7 步選 **①′ 自動抓取**，**名稱開頭**維持預設 `via` 即可（範例中的 via 名為 `via_0` ～ `via_3`）。
- 第一次練習建議**不要**勾「取代模式」，這樣原本的圓柱 via 會保留，方便對照漏斗形狀。

> 範例專案未內含求解結果，僅供建模流程練習；建完漏斗後不需要（也不建議）在練習專案上跑模擬。

## 四、介面說明

### 1. 連線設定（最上方）
- **AEDT 版本**：預設 `2026.1`（即 2026 R1），可改成實機安裝的版本。
- **via 材質**：預設 `copper`。
- **連線 AEDT**：接上目前已開啟的 AEDT／專案／設計，狀態列顯示目前設計名稱。
- **釋放連線**：結束控制，之後才能安全關閉 AEDT。

### 2. 疊構表 STACKUP（左）
- 由上往下列出每一層，格式：`kind,name,thickness[,layer]`
  - `kind` ＝ `soldermask` / `copper` / `dielectric`；`copper` 需填 `layer` 編號。
- 數值單位為 mil，可直接在框內編輯。
- **「⤵ 從 3D Layout 設計讀取真實疊構」按鈕（強烈建議使用）**：
  自動讀取**同專案的 3D Layout 設計**的真實層數與厚度，一鍵填好整張疊構表。
  - 採用 AEDT 原生 API（不依賴 pyedb），不必另選 EDB 資料夾。
  - 讀完會自動切回原本的 HFSS 設計。
  - 這是讓漏斗節點精準對齊每層銅箔的關鍵——手打疊構若層數或比例與模型不符，節點就會對不準。

### 3. Layer change 表（中）
- 只需填 `start,end`（每行一段雷射打孔），段數＝行數。
- **「↻ 依疊構自動產生（每相鄰銅層一段）」按鈕**：依疊構表的銅層數，自動產生每相鄰銅層一段（N 層 → N−1 段）。
- 進階：想個別覆寫某段寬度時才寫成 `start,end,drill,finish`（後兩欄會覆寫全域寬度）。

### 4. Via 寬度面板 ＋ 即時 3D 預覽（右）
- **寬端（上, Drill）**、**窄端（下, Finish）**：直徑（mil），套用到所有段。
- **3D 預覽**：隨數值與段數即時重畫漏斗剖面；可用滑鼠左鍵旋轉、滾輪縮放。
- **寬端＝原選取 via 外徑（自動帶入）**：勾選後立即把抓到的 via 外徑帶入「寬端」欄位並更新預覽；建立時每顆漏斗各自採用自己的外徑（外徑不一致時，預覽以第一顆為準）。

### 5. Via 來源
兩種抓取方式（擇一）：

- **① 抓取 AEDT 中『選取的 via』**：先在 AEDT 模型器手動框選／點選 via，再按此鈕。
- **①′ 自動抓取所有名稱開頭符合的物件**：不必手動選取，自動掃描整個設計。
  - **名稱開頭**：預設 `via`，不分大小寫。
  - 自動略過名稱含 `_funnel` 的物件（本工具先前產生的漏斗），避免重複處理。

兩個選項：
- **依 via 頭尾錨定＋疊構比例定位節點（建議）**：勾選後讓每節點落在真實層位置。
  - **若已按過「⤵ 從 3D Layout 設計讀取真實疊構」**，工具會自動升級為「真實層 Z 定位」：節點直接放在 layout 讀到的真實層 elevation，只用 via 做整體 offset 對齊（純平移、不拉伸），對 via 殘段（stub）／防焊免疫。執行訊息會印出每顆 via 的 `offset` 與「端點殘差」供驗證。
  - 若未讀 layout（僅手打疊構），則以 via 頭尾為錨點、依疊構比例定位。
- **取代模式**：建立漏斗後刪除原本的等徑圓柱 via。

> 另有「手動輸入座標」模式，可直接輸入 `x,y`（mil）逐顆建立。

### 6. 執行訊息（下方）
後端透過 WebSocket 即時推播進度與錯誤訊息，與 AEDT 中的實際動作同步。

## 五、操作流程（建議順序）

### 0. 前置準備：讓「原專案」同時含 3D Layout 與 HFSS 設計

本工具需要在**同一個專案**中同時存在：
- **3D Layout 設計** ── 疊構來源（工具以原生 API 讀取真實層 Z）。
- **HFSS 3D 設計** ── via 所在、漏斗建立的地方。

建議用下列方式備妥：

1. 在 **HFSS 3D Layout 設計**使用 **Export** 功能，輸出成一個**新專案**（內含轉出的 HFSS 3D 設計）。
2. 開啟該輸出後的新專案，於專案樹對其中的 **HFSS 設計**按右鍵 **Copy**（複製）。
3. 回到**原本的專案**（含 3D Layout 設計），於專案節點按右鍵 **Paste**（貼上）該 HFSS 設計。
4. 如此原專案即同時擁有 3D Layout 與 HFSS 設計。

> 若專案已同時具備這兩種設計，可略過本步驟。

### 正式流程

1. **開啟 AEDT** 與上述已備妥的專案，切到要加 via 的 **HFSS 設計**。
2. 雙擊 `start.bat`，等待瀏覽器自動開啟。
3. 確認 **AEDT 版本**，按 **連線 AEDT**。
4. 按 **「⤵ 從 3D Layout 設計讀取真實疊構」** → 疊構表自動填入真實層數與厚度。
5. 按 **「↻ 依疊構自動產生」** → 自動產生對應段數的 Layer change。
6. 設定 **Via 寬度**（寬端／窄端），或勾 **「寬端＝原 via 外徑」** 自動帶入；看著 3D 預覽確認形狀。
7. 選擇 **Via 來源**：
   - 大量 via 建議按 **①′ 自動抓取**（確認「名稱開頭」前綴正確）。
   - 或按 **① 抓取選取的 via**（需先在 AEDT 選取）。
8. **勾選「依 via 頭尾錨定＋疊構比例定位節點」**；視需要勾 **取代模式**。
9. 按 **② 建立漏斗 Via**，下方「執行訊息」即時顯示進度。
10. 按 **釋放連線**，回到 AEDT 存檔。

## 六、輸出驗證（若該案例有 non-functional pad）

部分案例的 via 在每層銅箔處會有一圈一圈的 **non-functional pad**，剛好標出每層的真實 Z。建立完成後切到側視角度檢查：

- ✅ **正確**：每一節漏斗的上下端剛好落在相鄰兩個 pad 之間，節點與 pad 對齊。
- ❌ **某節沒對齊 pad**：代表疊構表的層數或相對比例與模型不符。建議改用「⤵ 從 3D Layout 設計讀取真實疊構」重讀，再重建。

> non-functional pad 不是每個案例都有，僅作為「驗證」用途，不作為建立依據。

## 八、注意事項

- **疊構務必與模型一致**：建議一律用「⤵ 從 3D Layout 設計讀取真實疊構」自動帶入。
- **自動抓取** 比對的是整個設計中名稱符合前綴的物件，前綴需夠精準；若 via 命名沒有共同前綴，請改用手動選取。
- **直徑（粗細）** 由 Via 寬度面板的寬端／窄端決定，與 Z 範圍無關。
- 若 `create_cone` 在您的版本回報參數錯誤，工具已內建自動改用 `cs_axis` 的備援，通常不需手動處理。
- 桌面（Tkinter）版的操作說明請見 [操作說明_桌面版.md](操作說明_桌面版.md)。
