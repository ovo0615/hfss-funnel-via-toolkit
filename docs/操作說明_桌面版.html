HFSS 漏斗 Via 建模工具　操作說明

堆疊雷射微孔（stacked laser via）自動建模工具｜Ansys HFSS 3D × PyAEDT

一、工具用途

HFSS 3D Layout 只能建立「等徑圓柱 via」，無法做出漏斗狀（堆疊雷射微孔 / stacked laser via）的錐形孔。本工具透過 PyAEDT 在 HFSS 3D 模型器中， 以多段「圓錐台（cone frustum）」沿 Z 軸堆疊，組出上寬下窄的漏斗狀 via，並可直接對齊、 取代既有的等徑 via。

三、環境需求（需先安裝）

項目用途安裝方式
Ansys Electronics Desktop（含 HFSS）模擬主程式（預設 2026 R1）公司正式安裝版
PyAEDTPython 控制 AEDT（提供 ansys.aedt.core）。僅腳本版需要pip install pyaedt
TkinterGUI 介面Python 內建，免安裝
執行檔（.exe）版已內含 Python 與 PyAEDT，不必另外安裝；但仍需客戶端已安裝 AEDT/HFSS，因為本工具是去遙控你已安裝的 AEDT。

腳本版安裝完成後可先驗證（不報錯即代表 PyAEDT 可用）：

python -c "import ansys.aedt.core"

四、啟動工具

請先開啟 AEDT，打開要加 via 的 HFSS 專案與設計（保持開著），再依下列任一方式啟動工具：

方式 A：執行檔版（免安裝 Python，建議一般使用者）

直接雙擊 funnel_via_gui.exe 即可開啟工具。

方式 B：Python 腳本版

  1. 將本工具資料夾解壓到任意位置。
  2. 在該資料夾按住 Shift 並於空白處按右鍵，選「在這裡開啟 PowerShell / 終端機」。
  3. 輸入下列指令（在腳本所在資料夾執行，不需完整路徑）：
python funnel_via_gui.py
路徑會以你實際存放的位置為準，不必與本說明相同。

五、介面說明

1. 連線設定（最上方）

  • AEDT 版本：預設 2026.1（即 2026 R1），可改成實機版本。
  • via 材質：預設 copper。
  • 連線 AEDT：接上目前已開啟的 AEDT／專案／設計，狀態列顯示設計名稱。

2. 疊構表 STACKUP（左）

  • 由上往下列出每層，格式：kind,name,thickness[,layer]；kind＝ soldermask / copper / dielectric，copper 需填 layer 編號。單位 mil，可直接編輯。
  • 「⤵ 從 3D Layout 設計讀取真實疊構」按鈕（強烈建議）：自動讀取同專案的 3D Layout 設計真實層數與厚度，一鍵填好整張表。
    • 採用 AEDT 原生 API（不依賴 pyedb），不必另選 EDB 資料夾。
    • 讀完自動切回原本的 HFSS 設計。
    • 這是讓漏斗節點精準對齊每層銅箔的關鍵——手打疊構若層數/比例與模型不符，節點會對不準。

3. Layer change 表（中）

  • 只需填 start,end（每行一段雷射打孔），段數＝行數。
  • 「↻ 依疊構自動產生（每相鄰銅層一段）」按鈕：依疊構銅層數自動產生（N 層 → N−1 段），不必手動數。
  • 進階：個別覆寫某段寬度時寫成 start,end,drill,finish（後兩欄覆寫全域寬度）。

4. Via 寬度面板 + 即時預覽（右）

  • 寬端（上, Drill）、窄端（下, Finish）：直徑（mil），套用到所有段。
  • 側視預覽圖：隨數值與段數即時重畫漏斗剖面，直觀確認粗細與形狀。
  • 寬端＝原選取 via 外徑（自動帶入）：勾選後立即把抓到的 via 外徑帶入「寬端」並更新預覽；建立時每顆漏斗各自採用自己的外徑。

5. Via 來源

兩種抓取方式（擇一）：

  • ① 抓取 AEDT 中『選取的 via』：先在 AEDT 手動框選／點選 via，再按此鈕。
  • ①′ 自動抓取所有名稱開頭符合的物件：不必手動選取，自動掃描整個設計。
    • 名稱開頭：預設 via，不分大小寫。
    • 自動略過名稱含 _funnel 的物件（先前產生的漏斗），避免重複處理。

兩個選項：

  • 依 via 頭尾錨定＋疊構比例定位節點（建議）：勾選後讓每節點落在真實層位置（每節介於相鄰兩層之間）。
    • 若已按過「⤵ 從 3D Layout 設計讀取真實疊構」，工具會自動升級為「真實層 Z 定位」：節點直接放在 layout 讀到的真實層 elevation，只用 via 做整體 offset 對齊（純平移、不拉伸），對 via 殘段（stub）/防焊免疫，節點精準落在每層銅箔（pad）上。執行訊息會印出每顆 via 的 offset 與「端點殘差」供驗證。
    • 若未讀 layout（僅手打疊構），則以 via 頭尾為錨點、依疊構比例定位（對整體縮放誤差免疫）。
  • 取代模式：建立漏斗後刪除原本的等徑圓柱 via。
另有「手動輸入座標」模式，可直接輸入 x,y（mil）逐顆建立。

六、操作流程（建議順序）

0. 前置準備：讓「原專案」同時含 3D Layout 與 HFSS 設計

本工具需要在同一個專案中同時存在：

  • 3D Layout 設計 ── 疊構來源（工具以原生 API 讀取真實層 Z）。
  • HFSS 3D 設計 ── via 所在、漏斗建立的地方。

建議用下列方式備妥（讓 HFSS 設計與 3D Layout 設計同在原專案）：

  1. 在 HFSS 3D Layout 設計使用 Export 功能，輸出成一個新專案（內含轉出的 HFSS 3D 設計）。
  2. 開啟該輸出後的新專案，於專案樹對其中的 HFSS 設計按右鍵 Copy（複製）。
  3. 回到原本的專案（含 3D Layout 設計），於專案節點按右鍵 Paste（貼上）該 HFSS 設計。
  4. 如此原專案即同時擁有 3D Layout 與 HFSS 設計：工具可在 HFSS 設計建立漏斗，並從同專案的 3D Layout 讀取真實疊構。
若你的專案已同時具備這兩種設計，可略過本步驟。

正式流程

  1. 開啟 AEDT 與上述已備妥的專案，切到要加 via 的 HFSS 設計。
  2. 啟動工具，確認 AEDT 版本，按 連線 AEDT。
  3. 按 ⤵ 從 3D Layout 設計讀取真實疊構 → 疊構表自動填入真實層數與厚度。
  4. 按 ↻ 依疊構自動產生 → 自動產生對應段數的 Layer change。
  5. 設定 Via 寬度，或勾 「寬端＝原 via 外徑」 自動帶入；看著預覽圖確認。
  6. 選擇 Via 來源：大量 via 用 ①′ 自動抓取（確認前綴正確）；或 ① 抓取選取的 via。
  7. 勾選「依 via 頭尾錨定＋疊構比例定位節點」；視需要勾 取代模式。
  8. 按 ② 建立漏斗 Via，下方「執行訊息」即時顯示進度。
  9. 存檔在 AEDT 內進行即可。

七、驗證方式（若該案例有 non-functional pad）

部分案例的 via 在每層銅箔處會有一圈一圈的 non-functional pad，剛好標出每層真實 Z。建立完成後切到側視角度檢查：

  • ✅ 正確：每一節漏斗的上下端剛好落在相鄰兩個 pad 之間，節點與 pad 對齊。
  • ❌ 某節沒對齊 pad：代表疊構表層數或相對比例與模型不符。建議改用「⤵ 從 3D Layout 設計讀取真實疊構」重讀，再重建。
non-functional pad 不是每個案例都有，僅作為「驗證」用途，不作為建立依據。

八、注意事項

  • 疊構務必與模型一致：建議一律用「⤵ 從 3D Layout 設計讀取真實疊構」自動帶入。手打疊構若層數或相對比例和模型不符，漏斗節點就會對不準。
  • 自動抓取 比對整個設計中名稱符合前綴的物件，前綴需夠精準；若無共同前綴請改用手動選取。
  • 「依 via 頭尾錨定＋疊構比例定位節點」會把漏斗填滿原 via 並讓節點落在真實層位置，建議保持勾選。
  • 直徑（粗細）由 Via 寬度面板決定，與 Z 範圍無關；要貼合原 via 外徑就勾「寬端＝原 via 外徑」。
  • exe 版仍需客戶端已安裝 AEDT/HFSS，且版本對應 GUI 上填的「AEDT 版本」。
  • 若 create_cone 在你的版本回報參數錯誤，工具已內建自動改用 cs_axis 的備援，通常不需手動處理。
